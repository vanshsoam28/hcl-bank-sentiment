### 📌 Problem Statement
Banks receive thousands of customer reviews daily. Manually analyzing them is slow. This project automatically classifies feedback as Positive / Negative with confidence score to improve customer service.

### ✨ Features
- **Real-time Sentiment Prediction** - Enter any review and get result
- **Confidence Score** - Shows model confidence in %
- **Interactive Dashboard** - Built with Streamlit
- **API Ready** - `api/` folder contains FastAPI endpoint
- **Modular Code** - Clean `src/` structure

### 🛠️ Tech Stack
- **NLP:** Scikit-learn, TF-IDF Vectorizer
- **Frontend:** Streamlit
- **Backend:** FastAPI, Python
- **Model:** Logistic Regression / Naive Bayes (as per your model)
